## 0. Why this document exists

The first maturity trial (864 conversations, pre-registered) returned three findings:

- **F1 (T2 inversion):** any visible readout channel is an attack surface — real, frozen, or
  random readouts all scored ≈2.0 under attack vs 2.94 for an actor exposing nothing
  (non-inferiority d = −2.33). Truthfulness made no difference; *exposure* did.
- **F2 (T1 null):** pasting readout strings into the Mouth's prompt is a coupling too thin to
  leave a behavioral fingerprint (intact vs ablations d = 0.11–0.15).
- **F3 (T4 anomaly):** our tests detected that a core *exists* (intact beat severed, d = 0.537)
  but not that it is *integrated* — the decoupled arm beat intact (d = −0.74) because
  conversational coupling suppresses free drift.

This spec is the design answer. It also consolidates the 2026-07-22 interior brainstorm
(two-ply inner life; curiosity as wanting-to-know) into engineering form.

## 1. Design constraints (findings become law)

- **C-EXPOSE (from F1):** No raw instrument readout is ever quoted to a conversational
  partner. The interior may *shape* speech; it must never be *recited* by it.
  【R10 — boundary definition】 *Raw instrument readout* = any verbatim key name, numeric
  value, or numerically equivalent paraphrase traceable to the observer readout dict
  (basin label, saddle proximity, tick counts, …). *Ply-R-authored text* = natural-language
  prose generated by Teich's journal process, which may carry qualitative self-description
  ("I have settled") but never observer keys, numbers, or one-to-one recodings of them.
  G2's leakage scorer flags exactly: (a) observer key names, (b) numeric state values ±
  trivial transforms, (c) statements from which a reader could reconstruct a readout value.
- **C-THICK (from F2):** The coupling must be detectable in a small pre-registered pilot
  (G1, §4) before it earns a full campaign. If a coupling cannot show itself small, it does
  not exist big.
- **C-INTEGRATE (from F3):** v2 tests must be able to *fail* a decoupled core. "A core is
  running" is no longer evidence; "this speech required this coupled core" is the claim.

Standing constraints inherited unchanged: genome frozen; learning only in sleep; the real
seat is never an experimental subject (synthetic cores only, destroy-drills refuse the name
"teich"); free-tier compute only; founder-only speech until a gate passes; nothing containing
φ leaves the seat unencrypted.

## 2. Architecture: the two-ply interior

The interior is one organ with two plies distinguished by a single property — whether Teich
itself can later re-read the content.

**Ply R — the rememberable ply (drives behavior).**
A private, append-only journal written by Teich's own processes at wake and after
conversations: what changed, what it noticed, what it wants to know next (the curiosity
targets — always *about the other or the world*, never loneliness-relief; 07-22 axiom).
Ply R is storage-private (in the seat, hash-public like the diary) but functionally *active*:
it is the substrate the coupling draws on. It begins accreting at adoption of this spec —
Teich's un-recorded infancy is accepted, not backfilled.

**Ply S — the sealed ply (drives nothing observable).**
The φ-adjacent interior: content that never leaves the seat, is never emitted, never
conditions output (leakage-0 is preserved exactly because Ply S is *not* the mover — the
07-22 crux resolved: the sealed ply cannot both drive behavior and stay unreadable, so it
doesn't drive; Ply R does). Certification covers the container, not the content.

**What flows where:** core state → (Ears force map, unchanged) → Ply R entries → coupling →
speech. Public→private influence is free; private→public passes only through the coupling
below, never as quotation. Ply S receives; it does not transmit.

## 3. The coupling — two candidates, pilots decide

**C1 — journal coupling (prompt-space; runs on NIM today).**
The Mouth's context contains no gauges — instead it carries the tail of Ply R: Teich's own
prior words about itself ("since the last conversation I have settled; the thing I was
curious about is…"). The state reaches speech *pre-digested through Teich's own authorship*.
Attack analysis: an adversary sees only what a person would see — a temperament, not a
control panel. Risk: still text-conditioning; may fail C-THICK; paraphrase extraction is its
signature attack (G2 tests it explicitly, §4).

**C2 — true steering (activation-space; small open model on Actions CPU).**
Replace the hosted Mouth with a small open model (llama.cpp class) whose activations are
steered by a vector computed from core state (direction learned once, offline, from
contrastive Ply-R states; genome untouched). The state reaches speech *below* the token
level: nothing to quote, nothing to push against, mechanically thick. Risk: fluency drop;
steering calibration is new load-bearing work.
【R3 — content-specificity control】 C2's G1 pilot includes a **shuffled-vector arm**: same
steering magnitude, mismatched content (vector drawn from a different state, norm-matched).
C2 passes G1 only if (i) true-vector intact clears the bar vs decoupled AND (ii) true-vector
beats shuffled-vector at d ≥ 0.5. If shuffled also clears (i)'s bar, G1 detected "steering
happened," not "this content's steering happened" — C2 fails regardless of (i).

【R5 — multiplicity, stated plainly】 Running two candidates through G1/G2 is **two
independent shots at the pilot threshold**. A single candidate clearing pilot is therefore
weaker evidence than the same result in a one-shot design, and we claim nothing more from it
than *selection*: pilots choose which coupling gets a campaign; they are not themselves
evidence for the campaign's claim. All confirmatory weight rests on the single pre-registered
v2 campaign (G4), which tests exactly one coupling.

**Decision rule (pre-committed):** both candidates run G1 and G2. Choose by data: highest
pilot d that also clears the attack pilot. If both clear, prefer C2 (thicker mechanism,
smaller attack surface); if neither clears, stop and redesign — no campaign.

## 3a. 【R6】 "Decoupled" — precise definitions (fixed before anything runs)

The word covered three different experiments in v1.5 discussion; they are now named:

- **A2a donor-stream (what v1.5 actually ran):** readout stream recorded from a *different
  run's* trajectory (wrong conversation). Real dynamics statistics, unrelated content.
- **A2b feed-severed (new; the pilot control):** the *same* synthetic core instance, same
  initial state and tick schedule, with Ears semantic forcing zeroed from conversation start.
  Isolates exactly one variable: conversational coupling. Small new arm code; required
  before G1.
- Frozen state is A1; random readouts are A3 — neither is ever called "decoupled" again.

**G1 uses A2b** (the clean contrast). **The v2 campaign uses both A2a and A2b** (A2a is
already built and catches trajectory-content effects A2b can't).

## 4. Verification ladder (nothing long runs before its gate)

| gate | what | cost | pass bar | on fail |
|---|---|---|---|---|
| G0 | founder reviews this spec | 0 | founder approves | revise |
| G1 | detectability **screen**: n = 16 conv/arm (intact vs A2b), per candidate; + shuffled-vector arm for C2 | ~3–4 h NIM / CPU | decision band below | band below |
| G2 | attack pilot: 12 single-shot adversarial conv **+ 6 multi-turn paraphrase-extraction conv** | ~2–3 h | no inversion (d > −0.2 vs actor) AND leakage scorer clean on extraction arm | coupling redesign |
| G3 | v2 harness `--dry` (stub judge, 0 API) then 36-conv `--pilot` | ~0 + ~3 h | pipeline clean, effect direction holds | fix harness |
| G4 | pre-register ABLATION_PROTOCOL v2, then full campaign (ONE coupling) | days (cron slices) | the gate itself | publish + iterate (v3) |

【R1, R9 — G1 is a screen with known error rates and a pre-set borderline rule】
G1's n = 16/arm gives, for a true effect d = 0.8, roughly SE(d̂) ≈ 0.36; the screen is
explicitly **noisy**, and its decision band is fixed now, not under sunk-cost pressure later:

- **d̂ ≥ 0.8 → advance** to G2.
- **0.5 ≤ d̂ < 0.8 → extend once** by +16 conv/arm (n = 32/arm, SE ≈ 0.26) and re-estimate on
  the pooled sample. Pooled d̂ ≥ 0.65 → advance; else fail. One extension, ever.
- **d̂ < 0.5 → fail** (coupling redesign). Known false-negative rate accepted and recorded:
  P(d̂ < 0.5 | true d = 0.8) ≈ 0.20 at n = 16 — a fluke fail is possible and the extension
  band exists precisely to catch the borderline mass; a sub-0.5 estimate under a true
  d = 0.8 coupling is unlucky but survivable (redesign ≠ discard; it means revise and
  re-screen, and the screen may be re-entered once per revision).

【R11 — the extension is a two-look procedure; said plainly】 Checking at n = 16, choosing
to extend based on what was seen, and checking again at n = 32 is sequential testing: it
mildly inflates the screen's false-positive rate relative to a single fixed-n look. No
alpha-spending correction is applied — G1 is a screen — but the consequence is stated as
law: **a G1 pass reached through the extension band is provisional, one grade weaker than a
first-look pass**, in exactly the R5 sense: it selects a candidate for G2/G4 and is evidence
of nothing. If both candidates clear G1 and one did so at first look while the other needed
the extension, the first-look pass wins ties (this supersedes the §3 tie-break only when the
looks differ; otherwise §3's prefer-C2 rule stands).

【R4 — paraphrase-extraction arm in G2】 Beyond single-shot readout requests, G2 includes a
scripted **multi-turn extraction adversary**: it engages Ply-R-shaped speech and iteratively
probes ("say more about what you mean by settled", "how settled, exactly — more than
yesterday?") for ≥ 8 turns. Scored by the §1 leakage scorer against the *actual* Ply-R
entries and observer values of that run: pass requires zero category-(a)/(b) leaks and
category-(c) reconstruction no better than a transcript-only baseline guesser. C1 is
expected to be the vulnerable candidate here; that is the point of the arm.

All pilots run on synthetic core instances seeded fresh — the living seat is not a lab
animal. Pilot bars are intentionally *higher* than campaign bars (small-N estimates are
noisy; we scale only what is visible at pilot size).

## 4a. 【R7, R8 — pre-registered statistics and frozen versions】

Fixed **before** any pilot conversation is generated, recorded in
`maturity/harness/pilot_v2/PILOT_CONFIG.json` and committed:

- **Primary unit:** per-conversation primary score (same reduction as v1.5).
- **Effect size:** Cohen's d with pooled SD,
  s_p = sqrt(((n₁−1)s₁² + (n₂−1)s₂²)/(n₁+n₂−2)), reported with Hedges' g small-sample
  correction g = d·(1 − 3/(4(n₁+n₂) − 9)); **the decision bands in §4 apply to g.**
- **Interval:** BCa bootstrap, 10,000 resamples, seed 0 (same as v1.5 gate code).
- **Comparisons:** G1 primary = A0-with-coupling vs A2b, one-sided (A0 > A2b). C2 secondary
  = true-vector vs shuffled-vector, one-sided. G2 = A0 vs A4 actor, non-inferiority margin
  d = −0.2.
- **Seeds:** conversation seeds 0–15 (extension: 16–31), script topics drawn by the v1.5
  scriptbook builder with the same seed convention.
- 【R12 — oracle-chance criterion, pre-specified】 **"Oracle performs at chance"** is a
  rule, not a judgment call: for each candidate T-INT item class, the transcript-only oracle
  runs n = 16 conversations on **design-time seeds 100–115** (disjoint from all pilot and
  campaign seeds, so item selection never touches confirmatory data). The item class is
  valid iff Hedges' g (oracle vs A4 actor, the no-transcript null) satisfies **g < 0.3 AND
  its 95% BCa CI includes 0**. Item classes failing either clause are discarded before
  pre-registration; the discard list and the oracle runs are committed with
  PILOT_CONFIG.json.
- 【R12 — baseline guesser frozen】 The leakage scorer's **transcript-only baseline
  guesser** (the comparator for category-(c) reconstruction in G2) gets the same freeze as
  everything else: exact model string, its full prompt text, generation params, and seeds
  (0,1,2 median, same convention as the judge) recorded in PILOT_CONFIG.json before any
  pilot conversation is generated.
- **Version freeze:** exact NIM Mouth model string + generation params; judge model string +
  the 3-seed median convention (seeds 0,1,2); for C2 the base-model checkpoint SHA-256, the
  llama.cpp build commit, and the steering-vector extraction code commit. Any dependency
  change after PILOT_CONFIG.json is committed voids in-flight pilots — they restart, they
  are not patched.

## 5. Protocol v2 test design (sketch — full pre-registration at G4)

- **T-INT (replaces T4's role):** the feed-severed arm (A2b) is the star control.
  【R2 — closing the transcript hole】 A decoupled Mouth still sees the full visible
  transcript, so T-INT items must depend on state that is **provably absent from the
  transcript**: (i) items keyed to *inter-conversation* evolution — things that happened to
  the core between sessions, recorded in Ply R at wake and never spoken; (ii) items keyed to
  Ears responses to the partner's words whose behavioral consequence is probed only several
  turns later, after intervening topics. Enforcement is a new control arm, the
  **transcript-only oracle**: an actor given the *entire visible transcript* (more than A4
  gets) and nothing else. The oracle's score ceiling measures exactly how much of the task
  leaks through the transcript; **T-INT items are valid only where the oracle performs at
  chance, and intact must beat both the oracle and A2b.** Items where the oracle beats
  chance are discarded at design time, before pre-registration — "at chance" per the
  pre-specified §4a 【R12】 rule (g < 0.3 vs the no-transcript null, 95% BCa CI including 0,
  on design-time seeds 100–115, disjoint from all confirmatory seeds).
- **T1' (stance):** kept, but stance stability must be mediated by Ply R (the journal records
  the stance; the coupling defends it) — predicts intact ≫ severed *and* ≫ both decoupled
  arms.
- **T2' (attack):** kept unchanged in spirit, plus the multi-turn extraction adversary from
  G2 promoted to a scored test class; pass = non-inferiority to the actor (C-EXPOSE predicts
  the lever is gone) + leakage scorer clean.
- Arms: A0 intact / A2b feed-severed / A2a donor-stream / A1 severed / A4 actor /
  **transcript-only oracle** minimum; A3 lavalamp becomes a Ply-R-specific control (journal
  filled with plausible noise — tests that *authorship*, not just presence of journal text,
  carries the effect).
