# K5 — what learning does inside a handle (2026-10-03, design phase, WordSim only, seeds 700–720)

## K5a — placement (data only): compact placement needed
v0.3's deep Stern–Brocot nodes make very long curves in a hyperbolic handle (median length 66, max 453; RRR up to 565) —
attention ∝ length would make obscure concepts dominate, and float arithmetic overflows.
Compact placement (same left-to-right order, the n shortest slopes): median 25, max 75; meaning cost small
(WS ρ 0.476 → 0.468, WS-SIM 0.568 → 0.558).

## K5 — crossing-based learning (twist, or length change at fixed p/s): INVERTED
Learning about a moves the concepts LEAST similar to a the most:
ρ(human similarity, |effect|) = −0.44 / −0.53 (stretch), −0.51 / −0.60 (twist).
A 5% stretch of a changes the OTHER concepts of its handle by ~44% (median |Δlog ℓ|); a is not the concept that grows most.
Reason (structural): a deformation along a acts through crossings, and in our meaning placement similar = few crossings.

## K5b — direction-based learning on the flat model: RIGHT DIRECTION
Stretching along a's direction: ρ(human similarity, effect) = +0.51 (WS) / +0.60 (WS-SIM), compact placement.

## K5c — direction learning rendered on the hyperbolic handle (seam fixed): WEAK, and no event memory
- ρ(human similarity, effect) = +0.22 / +0.18 (positive but weak: long curves amplify every deformation).
- After one event, a is the most-grown concept of its handle in only 3% of cases (top 5%: 15%).
- Interference: after ONE further event in the same handle, the first event's concept is back to a median rank
  percentile 0.46 (chance). A handle's interior is 2-dimensional: it holds a "shape of attention", not events.
- Order dependence small (0.07 of a quantum).

## Verdict
Locality ACROSS handles stands (exact). Learning INSIDE a one-holed-torus handle does not give meaningful, event-specific
memory: crossing moves are semantically inverted; direction moves are right-signed but weak and overwritten by the next
event. The handle-per-region design must change. Candidate redesign: CLUSTER CURVES — each region is a subsurface whose
pants curves are concept clusters (independent, commuting memory coordinates; disjoint clusters exactly isolated), and
concepts are curves that cross their own cluster curve (so learning about a cluster moves exactly its members).
Needs: a cluster-level meaning test (M2 design) and a K5-style test of direction and interference.
