# K10 + K11 — cluster curves (2026-10-03, design phase, WordSim only, seeds 740–741)

## K10 — clusters from v0.3's concept tree: PASS (with adaptive cut needed)
Cluster = Stern–Brocot path prefix of length 3+k. Same-cluster pairs (same region) are judged more similar than
other-cluster pairs: AUC 0.74–0.76 (k=3, 64 clusters), 0.75–0.79 (k=4, 127), 0.79–0.83 (k=5, 232).
Tree relatedness ρ (all pairs) 0.434 / 0.522. Costs: unbalanced tree (k=4: median size 4, max 83 — "wider world"),
so cut adaptively by size; ~half of strongly related pairs fall in different clusters.

## K11 — one cluster = one handle; cluster curve = its core curve A; learning = lengthen A (FN, twist + seam fixed)
- The dial is readable: A's crossing rate +4.88% ± 0.22% for a +5.13% length change (Crofton).
- Isolation exact: other handle and seam change ≤ 1e-14 in length; in behaviour within 1.5 SE (A2 1.0041, B2 1.0000,
  A2B2 1.0028, C 1.0020).
- Members placed on the n SHORTEST slopes: NOT coherent — half go up, half down (Δ correlates −0.8 with how often a
  member crosses A: the collar effect).
- Members placed on the DEHN-TWIST ORBIT of a transversal (slopes 1/q, each crossing A exactly once): COHERENT —
  97% go up, median +4.87% for a +5% dial (32 members). Members crossing A on "both sides" (q/1 family) break it.
→ Rule: a cluster's members are T_A^k(B): "the cluster's theme, twisted k times". The inner language's Dehn twist along
  the cluster curve walks from one member to the next. Within-cluster relatedness = −log|k − k'| (a line, ordered by the
  dendrogram leaves).

## Verdict
The cluster-curve mind works: ~64–128 independent, exactly isolated, directly readable memory dials; learning moves a
whole cluster coherently and nothing else. Granularity is the cluster, not the single concept. Open: body cost at
genus ~100 (Dirichlet domain ~1,200 faces → need a pants-local body), within-cluster meaning test, adaptive cut, bridges.
