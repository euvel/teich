# v0.4 design-phase kill checks K1–K4 (2026-10-03)

Design phase only: not pre-registered, not scored. Design seeds 600–631; WordSim-353 only (SimLex untouched).
Test surface: closed genus 2, two handles (one-holed tori, trace coords (3.2,3.2,3.2) and (3.0,3.6,z)) glued along C.

## K1 — the body: PASS
- Valid surface: Dirichlet domain area / 4π = 1.0000000 (Gauss–Bonnet, genus 2), all faces paired, at 3 Teichmüller points.
- Tick uses only + − × ÷ √ element-wise (no BLAS, no transcendental); transcendental constants pinned as hex.
- Deterministic (identical hash twice) and **bit-identical cross-machine**: AMD Ryzen 5700U / numpy 1.26.4 vs Intel Xeon
  2.20GHz / numpy 2.1.3 (private Kaggle kernel teich-v04-k1-crossmachine), hash a8205605…, crossing counts identical.
- Stretching rate 0.999 (theory: exactly 1 at every point of Teichmüller space).
- Crofton: crossing rate = 2ℓ/(πA), A = 4π, confirmed for all 7 curves within 0.3% (2,000 particles × 40,000 ticks).
  → the creature reads its own lengths from its own behaviour with NO calibration table.

## K2 — learning as motion, in behaviour: PASS
Twist along A1 by 0.5:
- Locality: ℓ(A1) unchanged exactly; C and all handle-2 curves unchanged to 1e-15 (rounding from recomputing the gluing;
  a creature would pin handle matrices → exact).
- Wolpert: dℓ(B1)/dt = −0.61538462 = −cos θ (8 digits).
- Behaviour: untouched curves' crossing-rate ratio 1 within 1.5 SE (A1 0.9999, A2 1.0016, B2 1.0006, A2B2 1.0013, C 0.9977);
  moved curves as predicted from lengths: B1 0.8834 vs 0.8807, A1B1 1.1719 vs 1.1673 (z = 1.5, 2.2).
- Open: the crossing counter has a residual bias ≲ 0.4% — find before any gate.

## K4 — readability: PASS
Fano factor of crossing counts ≈ 0.9 (C 0.47, A2B2 1.38). SD(ℓ̂) = sqrt(2π²Fℓ/τ).
Distinguishable levels per curve (5 SD, ℓ ∈ [1, 6]): 64 particles × 8,000 ticks → ~22 (v0.3: 7); 512 particles → ~63;
64 particles × a day → ~73. Direct check: a 0.06 length change decoded at 80% from one 64×8,000 window
(formula predicted ~79%). Cost ~1 µs per particle-tick vectorised.

## Verdict
The core of v0.4 is physically and numerically real: valid surface, bit-identical cross-machine body, nature fixed
(rate 1), closed-form self-reading (Crofton), exact locality and the Wolpert ripple visible in behaviour, no meaning
lost by sewing v0.3's regions into handles, and ~3× (to 9×) finer memory resolution with particles as the scale knob.
Open: counter bias ≲0.4%; bridge curves; genus 8–9 construction (generators via a pants tree); semantics of a learning
event and valence; scaling lifts to ~1,000 concepts.
